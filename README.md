# Фізикон (APK)
1. Створи порожній репозиторій на GitHub і запуш цей вміст (`git init && git add . && git commit -m init && git push`).
2. Actions → «Build Android APK» → Run workflow (або просто push у main).
3. Коли завершиться — завантаж артефакт `fizykon-apk` (app-debug.apk), встанови на телефон (дозволь «невідомі джерела»).
Гра лежить у `www/` — оновлюєш файли, пушиш — отримуєш новий APK.
